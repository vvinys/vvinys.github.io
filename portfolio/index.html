macOS Desktop Widgets and Activity Detection

Widgets and desktop customization for the Mac, driven by a system that detects what's happening on macOS.

  • Desktop widgets that live alongside the user's wallpaper and windows.
  • Customization options so each user can style their desktop the way they like.
  • An activity detection system that watches macOS events, such as which app is in front.
  • Widgets that update and react to that activity as it happens.
